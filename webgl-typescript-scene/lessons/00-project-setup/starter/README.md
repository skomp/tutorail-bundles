# Starter project

Copy `package.json`, `package-lock.json`, `tsconfig.json`, `index.html` and `src/main.ts` to
their corresponding paths at the root of a new repository.

Run `npm install`, then:

- `npm run typecheck` checks TypeScript without emitting files.
- `npm run build` creates `dist/main.js` and its source map.
- `npm run serve` rebuilds, watches source files and serves the repository.

The starter intentionally contains no WebGL code.
